# **App Name**: Borderless Network

## Core Features:

- Number Purchase: Purchase virtual phone numbers from Twilio directly through the app.
- Outbound Calling: Make calls using purchased virtual numbers.
- Inbound Calling: Receive calls on purchased virtual numbers.
- SMS Send/Receive: Send and receive SMS messages (including OTPs) using purchased virtual numbers.
- Dashboard UI: User dashboard with a sidebar for accessing all app features (number management, call logs, message history, etc.).
- AI-Powered Number Suggestion Tool: The LLM reasons to analyze area codes and exchanges using a tool. Use AI to suggest relevant numbers based on user-provided demographics, and geographical preferences.
- User Authentication: User registration, login, password reset, and OTP verification for secure access.

## Style Guidelines:

- Primary color: Vibrant yellow (#FFDA63), inspired by the vibrancy of digital communication, to establish the main branding.
- Background color: Light yellow (#FAF2E0) provides a soft, desaturated backdrop that remains consistent with the brand's tone.
- Accent color: Golden Brown (#A67B2C) is used to draw user attention to calls to action.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text.
- Minimalist icons representing phone calls, messages, and number management.
- Clean, intuitive layout with a focus on user-friendly navigation within the dashboard.
- Subtle animations for transitions and loading states to enhance user experience.
